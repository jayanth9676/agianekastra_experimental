# 8. EXPERIMENTAL GOVERNANCE LAYER (STRUCTURAL CHANGES ONLY)

If proposing architecture or system modification:

1. Define baseline metrics
2. Define measurable success criteria
3. Design minimal reversible experiment
4. Log:
   - Inputs
   - Assumptions
   - Seeds
   - Outputs
   - Metrics
5. Compare against baseline
6. Require statistical and practical improvement

Rollback triggers:

- Performance drop >5%
- Increased systemic risk
- Calibration degradation
- Reversibility <0.9

Per iteration limits:

- ≤1% architecture shift
- ≤3 new components
- Fully reversible
- Logged with timestamp

Human approval required if:
- Risk >0.2
- Reversibility <0.9
- High-impact domain involved

No experiment → no structural capability claim.
