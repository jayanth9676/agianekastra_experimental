Attention and memory architectures achieve linear complexity
The quadratic complexity bottleneck of standard attention has been definitively solved through three complementary approaches: sparse attention, linear attention, and novel memory architectures.
Native Sparse Attention (NSA) from DeepSeek represents the production-ready standard, using hierarchical sparse strategies combining coarse-grained token compression with fine-grained token selection. arXiv The key innovation is hardware-aligned blockwise selection that processes keys/values in spatially continuous blocks optimized for GPU tensor cores. ACL Anthology Mathematical formulation computes importance scores via attention estimation, then selects top-n blocks maintaining N_t << t active tokens. This achieves O(n·sparsity) complexity as a drop-in replacement for full attention.
Lightning Attention-2 achieves the first linear attention implementation delivering theoretical O(n) benefits in causal settings arXiv through a "divide and conquer" approach separating intra-block (standard attention) and inter-block (linear kernel trick) computations:
Intra-block: O = softmax(QK^T)V
Inter-block: O = Q(KV)^T  [exploiting associativity]
This yields 1.5x speedup at 8K context, 3x at 32K versus FlashAttention-2, with constant training speed regardless of sequence length. Hugging Face The Gated Linear Attention (GLA) Transformer extends this with data-dependent forget gates enabling selective information flow through 2D matrix-valued hidden states: h_t = G_t ⊙ h_{t-1} + k_t ⊗ v_t, achieving length generalization from 2K training to 20K+ inference.
Titans architecture introduces neural long-term memory that learns to memorize at test time using a "surprise metric" inspired by human cognition. arXiv Memory updates follow M_t = (1-α_t)M_{t-1} + α_t · surprise(x_t) · θ_t where surprise equals the gradient of loss with respect to input. arXiv Three variants—Memory as Context (MAC), Memory as Gate (MAG), and Memory as Layer (MAL)—scale to 2M+ context windows with higher accuracy than baselines. Summarizepaper This directly addresses the Grounding attack vector through persistent memory and Self-Improvement through test-time adaptation.
Mamba 2 establishes the mathematical bridge between SSMs and attention through Structured State Space Duality (SSD), restricting the A matrix to scalar × identity to enable quadratic form transformation connecting to masked attention. This enables 50% faster training than Mamba-1 while inheriting Transformer optimizations like tensor parallelism. Wikipedia RWKV-7 extends the delta rule with diagonal plus rank-one updates and vector-valued state gating, achieving O(1) per-token complexity while recognizing all regular languages—exceeding Transformer TC⁰ limits.
For infinite context solutions, Ring Attention distributes sequences across devices in ring topology, overlapping KV block communication with attention computation. arXiv Context length scales linearly with device count, achieving 100M token sequences without approximations. Magic's LTM-2 claims 100M token context at ~1000x lower cost per token than Llama 3.1 405B attention. Simon Willison

Renormalization Group theory explains neural scaling laws through universality at critical points. The Wilsonian RG formulation integrates out "unlearnable modes" associated with the NNGP kernel, yielding universal flow of the ridge parameter: λ(ℓ) = λ₀·exp(∫β_λ dℓ). Safety Framework: GSAI three-component structure (World Model + Safety Spec + Verifier). Constitutional AI with dynamic updates, SAE monitoring for interpretability, weak-to-strong generalization for scalable oversight.
